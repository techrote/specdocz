# UI/UX specification families

The [specdocz overview](../README.md) describes authority, provenance and the agent-tailoring workflow. This category provides reusable GUI/TUI and editing-interface design baselines, optional implementation patterns and reference-backed examples.

Read a project's existing requirements before using a baseline. Review implementation patterns with **Adopt / Adapt / Reject / Extend** decisions; pin the exact specdocz revision and put the resulting contract in the consuming repository. Referenced projects illustrate precedent, not mandatory architecture.
