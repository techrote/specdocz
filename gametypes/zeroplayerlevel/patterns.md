# Zero-player creative and engineering pattern index

**Status:** Non-normative, derived from [canonical study §6](metastudy.md#6-mechanics-and-creative-pattern-library). IDs are stable discovery keys, not implementation requirements or evidence of feature completeness.

| ID | Pattern | Mechanism |
| --- | --- | --- |
| ZP-P01 | Gravity cascade | Dropped mass starts a physical event chain |
| ZP-P02 | Bounce corridor | Springs/launchers move an inert subject |
| ZP-P03 | Moving conveyor | Moving surfaces and/or forces transport objects |
| ZP-P04 | Pendulum relay | Contact transfers motion between hinged bodies |
| ZP-P05 | Funnel-and-gate | Sloped capture and timed physical release |
| ZP-P06 | Fluid messenger | Coupled cellular-material flow drives a rigid body |
| ZP-P07 | Near-miss aperture | Carefully timed passage near an obstacle |
| ZP-P08 | Triggered scenic reveal | Sensor event reveals a scene beat |
| ZP-P09 | Rhythm instrument | Physical contacts drive time-based cues |
| ZP-P10 | Endless kinetic loop | Bounded sustained kinetic display |
| ZP-P11 | Fixed-input variant | **Not** zero-input; continuously held control (PF/Keep) |
